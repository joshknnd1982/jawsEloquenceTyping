JAWS-style Eloquence typing

This add-on makes NVDA's typing, reading, and character-navigation feedback with the Eloquence synthesizer sound more like JAWS. All behavior is runtime-only: the add-on never modifies or saves NVDA's own configuration. Character echo must already be enabled in NVDA's Keyboard settings.

Why this only touches isolated characters

JAWS and NVDA can both drive the same underlying ETI-Eloquence engine, so differences in tone are not a different synthesizer - they come from how each screen reader hands text to it. During ordinary reading (say-all, line reading) with NVDA's Symbol/Punctuation level set to "Some" (matching JAWS's own Punctuation Level setting), terminal punctuation is not converted to a spoken word at all - the raw character passes straight through to Eloquence, which supplies its own native pause and pitch cadence. That already resembles JAWS closely and this add-on does not need to change it.

Where NVDA and JAWS audibly diverge is isolated character announcements: typed character echo, and arrow-key character navigation. There, NVDA speaks a symbol's name instead of the raw character, and some of NVDA's names differ from JAWS's wording (for example NVDA says "dot" for a period, where JAWS says "period"). This add-on intercepts exactly those isolated announcements.

What it does

  • Capital letters: indicated with a pitch offset (default +20, adjustable in settings) instead of saying "cap" or playing a beep - while typing and while navigating by character.
  • Question marks (?): sent to Eloquence as "question?" so its native rising question cadence is heard, instead of a flat spoken word.
  • Periods (.): sent as "period." (JAWS's wording, rather than NVDA's "dot") with Eloquence's native falling/pause cadence.
  • Exclamation points (!): sent as "exclaim!" (JAWS's wording, rather than NVDA's "bang") with native emphasis.
  • Commas (,): sent as "comma," with native pause cadence.
  • Semicolons (;): sent as "semicolon;" (JAWS's wording, rather than NVDA's "semi") with native pause.
  • Colons (:): sent as "colon:" with native pause cadence.

Each of the above is applied consistently for typed character echo and for left/right arrow character navigation.

Settings

Open NVDA menu > Preferences > Settings > JAWS Eloquence Typing to turn any of the above on or off individually, and to adjust the capital-letter pitch offset. Only the capital-letter and question-mark behavior has been checked by ear against real JAWS; the period/exclamation/comma/semicolon/colon handling follows the same approach but is newer. If any of them doesn't sound right to you, turn it off in settings - the underlying NVDA behavior for that character is left untouched when disabled.

For the closest overall match to JAWS

This add-on only affects isolated character announcements. For everything else (ordinary reading, overall voice tone):

  • Use the same Eloquence voice/variant in NVDA as in JAWS (e.g. "Reed").
  • Set NVDA's own Symbol/Punctuation level (Speech settings) to match JAWS's Punctuation Level setting (e.g. "Some").
  • Match NVDA's Rate/Pitch/Inflection/Volume sliders to JAWS's if you have customized JAWS's voice profile away from its defaults.

Updates

The add-on checks for updates. Once a day, a little after NVDA starts, the add-on asks its GitHub repository, github.com/joshknnd1982/jawsEloquenceTyping, whether a newer version has been released, and says nothing unless there is one. When there is, a dialog shows what's new in a box you can read line by line, and offers to download and install it. The download must match the release's SHA-256 checksum. Then NVDA asks you to confirm the installation and offers to restart. Your settings are kept.

To check yourself, open the NVDA menu, choose Tools, then Check for add-on updates, and choose JAWS-style Eloquence typing.... Or press Check for updates now in the add-on's settings: NVDA menu, Preferences, Settings, JAWS Eloquence Typing. You can also assign a gesture to Checks for JAWS-style Eloquence typing updates in NVDA's Input Gestures dialog, under JAWS-style Eloquence typing. To stop the daily check, clear Check for JAWS-style Eloquence typing updates automatically in the same settings panel.

Restart NVDA after installing or updating this add-on.
